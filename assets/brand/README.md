# Luke’s Picks brand asset

`lukes_picks_mark.svg` is an original geometric shield, scoreboard, and
checkmark created for this repository. It does not incorporate or derive from
any team, league, broadcaster, or sports-data-provider logo.

`lukes_picks_app_icon.svg` is the opaque, square platform-icon composition
derived from that mark. Platform PNGs are raster exports of this source.
